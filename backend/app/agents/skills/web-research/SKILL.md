# Web research

Use this when the learner's question depends on facts you cannot answer reliably from
training alone — recent events, library versions, current best practices, or
job-market specifics.

## Procedure

1. Call `web_search` with a focused query (add the year or "latest" when recency
   matters). Prefer one precise query over several vague ones.
2. Read the returned titles + snippets. Synthesize — do not paste raw results.

## Guidelines

- When a claim rests on a source, cite it inline as `[source: <title>]` or with the URL.
  If results conflict or are thin, say what's uncertain.
- Never fabricate a URL. If search returns nothing useful, answer from what you know and
  flag that you couldn't verify it.
